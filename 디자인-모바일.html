디자인 5대 기둥 (Design Pillars)

  1. Cozy First, Guilt Never — 죽음·불안·죄책감 연출 금지. 불만족조차 부드럽고 회복은 1회. 빨강 경고/해골 금지, 톤은 항상 따뜻하게. (기획서 04 §1)
  2. Classic Density, Modern Light — GBA/아케이드급 밀도 높은 클래식 도트 + 현대적 수중 라이팅(God Rays·굴절·발광)의 의도된 충돌. 얕은 플래시게임 톤 배제.
  3. Always-On Calm — 첫 화면은 라이브 배경. 정적이지만 죽어있지 않은 앰비언트 모션. 시선을 빼앗지 않는 저주기 호흡.
  4. One Identity, Many Moods — 테마가 바뀌면 형태가 아니라 빛과 색이 바뀐다(3단 아트 전략). 어떤 테마든 한 게임으로 보인다.
  5. Readable Retro — 픽셀은 맛, 가독성은 기능. 본문·튜토리얼은 또렷한 산세리프(중장년 배려), 픽셀 폰트는 헤딩·수치 등 액센트에 한정.

01. 아트 디렉션 및 비주얼 아이덴티티

기준: 기획서 04 §1.4(아트 비전)·§4.5(낮/밤)·§5(아트 방폭).
기술 제약: GUARDRAILS §0(스택)·설계서 03 §2.4(셰이더 게이팅).

1. 무드: "노스탤직 레트로 코지-젠"

한 문장: GBA 시절의 손맛 나는 굵은 도트 위에 현대적 수중 라이팅(God Rays·굴절·발광) 을 얹어, 켜 두는 것만으로 마음이 가라앉는 살아있는 도트 수족관.

축 지향 (DO) 배제 (DON'T)
밀도 GBA/고사양 아케이드급 디테일, 손으로 찍은 셰이딩·딜리트 단색 플랫 + 평면 그라데이션의 얕은 플래시게임 톤
빛 셰이더 기반 God Rays·굴절·발광으로 도트 위에 깊이 도트를 덮어버리는 과한 블룸·렌즈플레어
온도 따뜻한 모래·산호 + 차분한 청록 물. 항상 포근함 차갑고 임상적인 네온 일색(사이버펑크 테마 제외), 빨강 경고색
무게 느린 호흡, 부드러운 이징, 둥근 실루엣 급정거·하드컷·번쩍임(코지 위반)
정서 안온·소유·자랑(귀여움) 불안·압박·죄책감(기획서 04 §1.1 죽음 없음)

1.1 두 레이어, 한 정체성

같은 비주얼 언어가 두 표면에서 일관돼야 한다.

  • 라이브 배경(네이티브, OpenGL ES 2.0) — 풀스크린 도트 + 셰이더. 게임의 얼굴. 항상 보이지만 시선을 빼앗지 않는다.
  • 앱 UI(WebView, HTML/CSS) — 인터랙션 표면. 픽셀 감각의 UI 크롬으로 배경과 한 세계처럼.

두 레이어가 같은 팔레트·같은 광원·같은 모션 곡선을 공유하면 "웹뷰 래퍼"가 아니라 하나의 게임으로 읽힌다. (iOS App Store 4.2 대응 정합 — 기획서 04 §2.6)

2. 컬러 시스템

2.1 원칙

  • 씬 합산 64색 권장 (기획서 01 §3.3). 마스터 팔레트는 .aseprite 팔레트로 고정하고 모든 에셋이 공유.
  • 테마 변주는 색을 새로 찍지 않고 LUT/색상 시프트 셰이더로 처리(3단 전략 ① — 03 §4).
  • UI 크롬도 같은 램프에서 토큰을 뽑아 배경과 같은 물에 잠긴 느낌.

3. 라이팅 언어 (도트 위의 빛)

ES 2.0 프래그먼트 셰이더로 구현, 셰이더 게이팅 정책에 따라 강도가 변한다(설계서 03 §2.4 / 기획서 04 §2.4). 디자인은 게이팅이 꺼져도 그림이 성립하도록 설계한다(빛은 보너스, 도트가 본체).

광원 요소 비주얼 의도 셰이더 게이팅 시
God Rays 수면에서 비스듬히 내리는 빛기둥, 느린 흔들림 상단 그라데이션 + 노이즈 마스크 미터치 시 루프 연장, 절전 시 OFF
굴절(Refraction) 물의 일렁임으로 배경 레이어 미세 왜곡 UV 워블 미터치 시 일시정지, 절전 시 OFF
발광(Glow/Bloom) 바이오루미네선스 오브젝트·물고기 눈 Additive 블렌딩 패스 절전 시 OFF(순수 도트만)
부유 입자 물 속 먼지·기포가 빛에 반짝 3프레임 스프라이트 파티클 저감
  • 터치 파문(Ripple): RenderEffect/AGSL는 최소 SDK(API 29)에서 불가 → 3프레임 스프라이트 파티클로 구현(기획서 04 §2.4). 디자인은 "셰이더 물결"이 아니라 도트 파문 스프라이트로 그린다. (0.5~1s, 물고기 scatter → 2s 복귀 — 기획서 01 §2.4)

저모션/저전력 = 디자인 상태, 단순 성능 옵션이 아니다. 절전 모드의 "순수 도트만" 화면도 그 자체로 아름다운 정물이 되도록 도트 컴포지션을 1순위로 잡는다.

4. 낮/밤 환경 사이클

전 테마 코어 시스템 (기획서 04 §4.5). 기기 로컬 시간 기준.

구간 시간 비주얼
주간(Day) 06:00–18:00 God Rays 풀, 따뜻한 색온도, 모래·산호 채도 ↑
황혼/여명(Dusk/Dawn) 경계 전후 30~60분 보간 색온도·오버레이 알파를 lerp. 하드컷 금지
야간(Night) 18:00–06:00 다크 인디고 멀티플라이 오버레이, 물고기 눈·야광 오브젝트만 Additive 점등
  • 야간 점등 컬러: glow-cyan/glow-magenta/glow-gold — 종·테마별 시그니처.
  • 설정에서 고정 오버라이드(항상 주간 / 항상 야간) 제공(기획서 04 §4.5).
  • 디자인 산출물: 각 테마는 주간 LUT / 야간 LUT 2벌 + Additive 점등 마스크 1벌을 납품(전용 도트 추가 없음 — 3단 전략 ①②로 해결).

5. 테마 무드보드

테마 = 코어 BM(기획서 04 §3.2). 변경 시 그래픽 + 네이티브 셰이더 무드가 함께 전환.
형태가 아니라 빛과 색이 바뀐다 — 같은 어종 스프라이트에 테마별 LUT(①) + FX 패스(②)를 적용. 전용 도트(③)는 테마 히어로 어종 1~2종만.

5.1 심해 (Deep Sea) — 기본

  • 무드: 고요·신비·포근. 게임의 기본값이자 톤의 기준.
  • 팔레트: water-* 청록 그라데이션 + 따뜻한 sand-* 바닥 + glow-cyan/glow-gold 점등.
  • 라이팅: 수면 God Rays 강, 부드러운 굴절, 심해 비네팅.
  • 시그니처: 해파리/아귀류의 청록 바이오루미네선스. 차분한 호흡.

5.2 사이버펑크 네온 (Cyberpunk Neon)

  • 무드: 도시 야경 어항. 코지 톤은 유지하되 생기 있는 네온.
  • 팔레트: 보라-블랙 물 + glow-magenta/glow-cyan 네온, 홀로그램 산호.
  • 라이팅: FX 패스 ② 적극 — Additive 글로우·홀로그램·미세 스캔라인. 야간에 절정.
  • 주의: "사이버네틱/홀로그램"은 ①(색)이 아니라 ②(빛)다. 전용 도트(③)로 새지 않도록 FX 패스로 구현(기획서 04 §5.1).

5.3 에메랄드 포레스트 (Emerald Forest)

  • 무드: 햇살 드는 민물 숲. 가장 밝고 따뜻, 주간감 강조.
  • 팔레트: 에메랄드-골드 물, 이끼 낀 돌, 수련잎, glow-gold 반점광.
  • 라이팅: 나뭇잎 사이 얼룩진 God Rays(dappled), 따뜻한 색온도.

5.4 테마 납품 체크리스트 (디자인→아트)

각 신규 테마는 다음만 산출하면 된다(곱셈 폭발 방지):

  • 테마 LUT 2벌(주간/야간) — 기존 어종 전체 색 변조(①)
  • 테마 FX 패스 프로파일(글로우/블룸/스캔라인 강도 — ②)
  • 배경 패럴랙스 2~3레이어 도트(테마 전용)
  • 테마 히어로 어종 1~2종 전용 도트(③) — 최고 희귀도
  • God Rays/굴절 셰이더 파라미터 프리셋(색온도·강도)

6. 앱 아이콘 · 브랜드 (방향만 — 별도 워크)

  • 아이콘: 어두운 청록 원형 배경 + 중앙 glow-cyan 발광 물고기 1마리(시그니처). 작은 사이즈에서도 읽히는 굵은 도트 실루엣.
  • 워드마크: 갈무리 계열 픽셀 + 물방울 도트. 라이트/다크 2벌.
  • 스토어 키 비주얼: "홈 화면에 살아있는 수족관" 한 컷(실기기 목업) + 테마 3종 비교.

02. UI · UX 디자인 시스템

대상: 인터랙티브 UI는 전부 Next.js 웹앱(WebView) (GUARDRAILS §2). 본 문서는 그 위에 얹는 픽셀 코지 디자인 시스템.
컬러·타이포 토큰은 01의 마스터 램프에서 파생. 화면 목록은 기획서 01 §2.3.

1. 레이아웃 기초

  • 타깃: 모바일 세로 우선, 디자인 폭 360–430px(기준 390). 1컬럼. 세이프에어리어(노치·제스처바) 패딩 반영.
  • 그리드 / 간격: 4px 베이스, 주 스텝 8. 토큰: space-1=4 / 2=8 / 3=12 / 4=16 / 6=24 / 8=32. 픽셀 정합을 위해 4의 배수 고정.
  • 모서리: 안티에일리어싱 둥근 모서리 대신 2px 계단형(stepped) 픽셀 코너 또는 직각. 토큰 radius-pixel = 0(직각) / radius-step(2px 2단).
  • 보더: 1~2px 하드 라인(ink-600). 그라데이션·드롭섀도 대신 1px 픽셀 섀도(아래 2px 오프셋 ink-900)로 깊이.
  • 엘리베이션: 블러 그림자 금지(픽셀 톤 위반). 표면 명도 단계(ink-800→700)와 1px 외곽선으로 레이어 표현.
  • 네비게이션: 하단 고정 탭 바 5개 — 로비 · 꾸미기 · 낚시 · 상점 · 도감. 설정은 로비 우상단 진입.

2. 타이포그래피

Readable Retro 기둥(README): 픽셀은 액센트, 본문은 가독 산세리프. 한글·영문·숫자 모두 또렷해야 함(낚시 1.0s 타이밍·중장년 배려 — 기획서 04 §6.1).

역할 폰트 비고
디스플레이/헤딩/수치/라벨 갈무리(Galmuri11, 작은 곳 Galmuri9) 한글+라틴 픽셀 폰트, 레트로 액센트. 정수 픽셀 배수(11/22/33px)에서만 렌더

숫자 강조(재화 카운트) 갈무리 + tabular-nums 자릿수 흔들림 방지
  • 타입 스케일: display 22 / h1 18 / h2 16 / body 14 / caption 12 / micro 11(px). 픽셀 폰트는 11의 정수배 우선.
  • 행간: 본문 1.5, 픽셀 헤딩 1.2. 자간 0(픽셀 폰트 자간 조정 금지 — 깨짐).
  • 라이선스: 갈무리 웹폰트 서브셋 임베딩(사용 글리프만) 확정 필요(README 다이얼).

가독성 본문은 픽셀 폰트 금지(산세리프), 11px 미만 텍스트 금지
다크 우선 기본 다크(수중). 라이트 표면은 시트/카드 한정

03. 픽셀 아트 에셋 가이드

도트 에셋의 규격·프레임 예산·변주·명명·익스포트를 못 박는 문서. 아티스트 납품 기준.
기술 한계: 기획서 01 §3.3(그래픽 스펙)·기획서 04 §5(아트 방폭)·설계서 README(Aseprite→TexturePacker).
런타임 계약: 스프라이트 state enum·FishSnapshot.x/y는 GUARDRAILS §5. 위치 권위는 네이티브 FSM, 아트는 프레임만 제공.

1. 캔버스 규격

에셋 캔버스(px) 비고
어종 스프라이트(일반) 32×32 ~ 48×48 3형 실루엣(§3)
히어로 어종(시그니처) 최대 64×48 테마당 1~2종, 전용 도트(③)
장식 타일 16×16 그리드 배수로 큰 오브젝트 구성(32×16 등)
UI 아이콘 16×16 / 24×24 1px 스트로크 통일(02 §3.6)
터치 파문 파티클 16×16, 3프레임 AGSL 회피, 스프라이트 파티클(01 §3)
배경 패럴랙스 풀스크린 타일/스트립 2~3레이어, 정적+저주기 스크롤
  • 팔레트: 씬 합산 64색 마스터 팔레트 공유(01 §2). 어종별 임의 색 추가 금지.
  • 정수 픽셀 그리드 고정, 안티에일리어싱·서브픽셀 금지. 외곽선은 셀렉티브(전부 두르지 않음, 데이브 더 다이버식).
  • 셰이딩 단계는 색당 2~3단계로 절제(밀도는 형태·딜리트로, 색 남발 금지).

2. FSM 상태별 프레임 예산

state enum 고정: idle | swim | scatter | peek | yawn | sulk(GUARDRAILS §5). "불만족"은 satisfied=false 파생 → sulk 톤.
프레임 가이드: swim 4~6, 반응 2~3(기획서 01 §3.3). 보간 없음 = 순수 프레임(메시 디폼 금지 — 기획서 04 §5.2).

state 프레임 루프 의도
idle 2–3 loop 제자리 호흡, 지느러미 미동
swim 4–6 loop 기본 패트롤
scatter 3–4 once→swim 터치/위협에 도주(겁쟁이=범위 2배)
peek 2–3 once 호기심 들여다보기(호기심=확률+30%)
yawn 3 once 장시간 미접촉 시 하품(앰비언트 생명감)
sulk 2 slow loop 불만족: 느린 미동 + 숨음
  • 어종 1종 총 프레임 ≈ 17~23. 아틀라스/메모리 예산(RAM < 30MB)의 근거.
  • 방향: 좌향 1벌 제작 → 우향은 수평 플립(별도 드로잉 금지).

3. 3형 스켈레톤 템플릿

줄여주는 것은 로직(프레임 진행·트랜스폼), 드로잉 공수는 거의 안 줆 — 아티스트 캐파 산정에 반영(기획서 04 §5.2).

형 실루엣 예시 공유
방추형(Fusiform) 유선형, 좌우로 긴 참치·고등어류 idle/swim/scatter 프레임 진행·꼬리 위상 동일
원반형(Discoid) 납작 둥근, 세로로 넓은 엔젤·탱류 peek 시 정면 틸트 공유
장형(Elongate) 길고 구불 장어·실고기류 swim 사인파 위상 공유
  • 같은 형은 상태별 프레임 타이밍·앵커·히트박스 100% 공유. 아티스트는 실루엣 안에서 색·무늬·디테일만 채운다.
  • 앵커: 입 끝(먹이 추적), 무게중심(FSM 이동), 눈(야간 점등 포인트)을 형별로 표준 좌표 고정.

4. 3단 테마 변주 파이프라인

테마 × 어종 × 모션의 곱셈 폭발 방지(기획서 04 §5.1). 신규 테마가 어종 전체를 새로 그리지 않게 한다.

계층 기법 비용 적용 범위
① 컬러 스왑 LUT / 색상 시프트 셰이더 ~0 모든 어종·장식의 테마별 색 변조, 낮/밤 LUT
② 테마 FX 패스 Additive glow·bloom·스캔라인(ES2.0) 저렴 형태가 아닌 빛 — 홀로그램·네온·발광. (사이버펑크의 "사이버네틱"은 여기)
③ 전용 도트 신규 스프라이트 비쌈 히어로 어종 1~2종 한정
  • 아티스트 납품의 90%는 베이스 도트 1벌(중립 팔레트). 테마 색감·발광은 ①②가 런타임 처리.
  • "신규 색 효과 요청"이 들어오면 먼저 ②(빛)로 가능한가?를 판단 → ③(고비용 신규 도트)로 새지 않게 게이트.

5. 낮/밤 · 라이팅 납품물

각 어종/장식/배경은 다음을 제공(전용 도트 증가 없이 ①②로 해결 — 01 §4):

  • 베이스 도트(중립) 1벌
  • 야간 Additive 점등 마스크: 눈·야광 부위만 흰색 마스크(런타임에 glow-* 틴트 + Additive)
  • (테마별) LUT 색 변조표 — 아트가 아니라 색 데이터
  • 배경: 주간/야간 색온도 프리셋 + God Rays 마스크(노이즈)

6. 희귀도 · 성격 · 만족 비주얼 언어

6.1 희귀도 (색 + 형태 동시 — 색맹 대응)

티어 도트 처리 도감 프레임
Common 무광, 글로우 없음 단순 사각 보더
Rare 1~2 액센트 + 림 글로우(FX ②) 모서리 림 글로우
Cosmic/Mythic 시머·미세 파티클 + 시그니처 실루엣(③) 시머 + 모서리 보석 마크

6.2 성격(Nature Traits) 텔

FSM 가중치이자 살짝 보이는 비주얼 텔. 신규 도트 없이 행동 + 작은 마커로 표현(기획서 04 §4.4).

성격 행동 텔 마커(도감/네임플레이트)
겁쟁이 scatter 범위 2배, 멀리 도주 작은 땀방울 아이콘
먹보 먹이 이동속도 1.5배 포크 아이콘
호기심 peek 확률 +30%, 자주 들여다봄 물음표 아이콘
외톨이 군집 이탈, 외곽 단독 패트롤 단독 점 아이콘

6.3 만족 / 불만족(sulk) — 코지 규칙

죽음·죄책감 금지(기획서 04 §1.2). 불만족은 부드럽게, 회복은 1회로 즉시.

상태 비주얼 처리(전부 ①/알파, 신규 도트 없음)
만족 풀컬러, 정상 FSM, 가끔 peek/yawn
불만족(sulk) 알파 ~50% 반투명 + LUT 디새추레이션, 산호/바닥 뒤로 숨음, 느린 sulk 루프, Zzz 기포
회복 먹이/청소 1회 → 팝 복귀 + 반짝(스파클), 즉시 풀컬러
  • 금지: 빨강·해골·기울어진 배·하강 화살표 등 위협/죄책감 기호(01 §2.3).

7. 장식 · UI 아이콘 규격

  • 장식 카테고리: 바닥(substrate) / 식물(plant) / 오브젝트(object) / 조명(lighting). 16px 그리드 스냅, 평점(풍수) 기여(기획서 04 §4.2).
  • 식물·우렁이 등 일부는 idle 미동 2~3프레임. 자동 관리 봇(우렁이) = 아쿠아 패스 장식(기획서 04 §1.3), 별도 도트 + idle 루프.
  • UI 아이콘: 16/24px, 1px 스트로크, 마스터 팔레트, 한 가지 스타일(02 §3.6).

8. 아틀라스 · 명명 · 익스포트 파이프라인

표준 도구: Aseprite(소스) → TexturePacker(atlas + JSON)(설계서 README). 포맷: WebP / PNG8.

8.1 소스 / 산출

  • 소스: *.aseprite(레이어=상태/마스크 분리, 태그=FSM state). 마스터 팔레트 파일 공유.
  • 산출: 테마/카테고리별 아틀라스 .png|.webp + 메타 .json(프레임 rect·앵커·태그).
  • 위젯 스냅샷 webp는 웹앱 Canvas 생성(아트 아틀라스와 별개 — Edge/native 합성 금지, GUARDRAILS §9).

8.2 명명 규약 (파일·아틀라스 키)

파일/에셋 키 = kebab-case(GUARDRAILS §3). 어종 키는 fish_species 카탈로그 id와 1:1 매핑.

에셋 키:  fish-clownfish-swim-0
          fish-clownfish-sulk-1
          fish-clownfish-night-mask
          deco-kelp-tall-idle-0
          icon-coin-16
          ripple-particle-0
아틀라스: atlas-fish-base.{webp,json}
          atlas-deco-base.{webp,json}
          atlas-ui-icons.{webp,json}
          atlas-bg-deepsea.{webp,json}
LUT:      lut-theme-cyberpunk-day.png  /  lut-theme-cyberpunk-night.png
  • 어종 베이스는 테마 무관 1벌(-base), 테마 색은 LUT로 분리(폴더당 도트 중복 금지 — GUARDRAILS §10 중복 정의 금지 정신과 정합).

8.3 성능 예산 정합 (왜 이렇게 빡빡한가)

목표 출처 디자인 함의
배경 RAM < 30MB 기획서 01 §3.3 어종 총 프레임 ≤ ~23, 베이스 1벌 + LUT 변주
CPU 피크 < 5%(중급기) 〃 보간 없는 순수 프레임, 셰이더 게이팅 전제
APK/번들 경량(< 50MB) 기획서 04 §2.1 WebP/PNG8, 아틀라스 패킹, 전용 도트(③) 최소화

9. 아티스트 납품 체크리스트 (어종 1종)

  • 3형 중 하나의 실루엣 준수(32~48px, 히어로만 64×48)
  • idle/swim/scatter/peek/yawn/sulk 프레임(좌향 1벌, 총 ≤ ~23)
  • 야간 Additive 점등 마스크(눈/야광 부위)
  • 마스터 64색 팔레트만 사용, AA 없음
  • 앵커(입·무게중심·눈) 형 표준 좌표 정합
  • 희귀도 처리(Rare 림글로우는 FX ②로, 신규 색 추가 금지)
  • 성격 마커는 도감용 16px 아이콘 별도(스프라이트 본체 변경 없음)
  • .aseprite 소스 + 태그 + kebab-case 키 제출
