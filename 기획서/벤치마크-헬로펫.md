# 벤치마크 — 헬로펫 (Hellopet)

> 2026-07-26 조사. Aqua Desk와 구조 유사성(홈 화면 상주 생명체 + 수집/애착 + 확정 구매)이 가장 높은 국내 선행 사례.
> 출처는 각 절 하단. 불확실 항목은 (추정)으로 표기.

## 0. 한 줄 결론

**"홈 화면에 사는 생명체" 시장은 실증됐고(누적 1,300만 DL, 10년 생존), 선두는 2018년 이후 콘텐츠 정체로 비어 있다.**
헬로펫의 성공 공식(확정 구매·페르소나 애착·폰 도우미)은 채택하고, 실패 공식(콘텐츠 정체·오버레이 기술 부채·iOS 차별·오퍼월 불신)은 우리 설계가 이미 대부분 회피하고 있음을 확인했다.

## 2. 코어 구조 (vs Aqua Desk)

| 축 | 헬로펫 | Aqua Desk |
|---|---|---|
| 상주 방식 | **SYSTEM_ALERT_WINDOW 오버레이** — 홈+모든 앱 위에 펫 표시 | **라이브 월페이퍼(GLES2)** — 홈/잠금 배경 |
| 권한 | 43~51개 (연락처·전화상태·마이크·부팅재시작 등) | INTERNET 1개 |
| 상시 실행 | 백그라운드 상주 + 상태바 알림 + 부팅 재시작 | OS가 배경을 관리(프로세스 상주 불필요), 가시성 게이팅 0fps |
| 부작용 | "화면 오버레이 감지됨" 타 앱 충돌(악명), 권한 온보딩 마찰, 절전에 죽음 | 배경은 충돌 없음. 대신 **앱 위까지 따라다니는 존재감은 오버레이가 우위** (인지된 트레이드오프) |
| iOS | 오버레이 불가 → 앱 내 마이룸만 → **"차별 대우" 불만 고착** | 위젯+미러 "체감 동등화" 전략 (기획서 §3) — 같은 구조적 문제, 커뮤니케이션이 관건 |
| 획득 방식 | **확정 구매**(쿠키 지정가) + 무료 경로 2개(광고로 '동작' 모으기, 친구 추천) — 가챠 없음 | **확정 분양** — 동일 철학 (GUARDRAILS §6) |
| 재화 | 쿠키(유료) + 하트(무료, 꾸미기 전용) | 코인/진주(+스태미나/하트) — 유사한 이중 구조 |
| 광고 | 리워드 영상 + **오퍼월 6종**(미적립 불만 다수) | 리워드 영상만 (오퍼월 배제 — 유지할 것) |
| 애착 장치 | 펫별 이름·성별·성격·**말투**(사투리·존댓말·중2병), 펫 간 관계 서사, 음성인식 반응, 말풍선 | nature 4종 행동 가중치 (서사 레이어는 미설계 — 아래 §4-1) |
| 소셜 | 펫카페(인게임 SNS — **유해성 문제**), 방명록, 친구 화면에 펫 방문 | 공유 토큰 뷰어 + 하트 (익명·저마찰 — 유지) |
| 리텐션 | 출석, 도감+펫마스터 칭호, 14단계 가이드 퀘스트(펫마스터 로드), 미니게임, 폰 도우미(시간/배터리/부재중/날씨) | 낚시 스태미나 루프, 도감 버프, 오프라인 적립 |

## 3. 검증된 성공 요소 → 채택

1. **확정 구매가 이 장르의 정답** — 헬로펫은 가챠 없이 10년 수익화. 우리 확정 분양 노선의 강한 실증.
2. **"광고 N회 = 확정 획득" 퍼널** — '동작 모으기'(펫당 6~32개, 영상 광고로 수집→완성 시 무료 입양)는 진행도가 보이는 광고 설계라 불신이 적음. → 우리 리워드 광고에 "광고로 어종 도감 조각 모으기 → 완성 시 확정 분양" 구조 검토 가치 높음.
3. **폰 도우미 기능이 상주의 명분** — 시간·배터리·부재중·날씨를 펫이 알려줌 = "장식이 아니라 쓸모". → 수족관 위젯/배경에 시계·날씨 연출(비 오면 수면에 빗방울 등) 로드맵 반영.
4. **가이드형 진행(펫마스터 로드)** — 단계마다 펫을 '선물'하는 온보딩. → 튜토리얼 낚시→첫 물고기 확정의 매직 모먼트(설계서/03 §9)와 동일 계열, 이후 14단계식 확장 검토.
5. **친구 추천 = 무료 입양** — 우리 공유 토큰에 추천 보상(추천인·피추천인 모두 확정 보상) 얹기 좋은 자리.
6. **동일 종 복수 보유 허용** — 돼지냥이 150마리 입양 사례. 우리도 동일 어종 복수 보유 허용(이미 스키마 상 가능) 유지.

## 4. 실패 요소 → 회피

1. **콘텐츠 정체가 사인(死因)** — 2018년 이후 신규 펫 0. 도트+개별 행동 32개 제작비가 원인(추정). → **우리 3단 분리 전략(① LUT 팔레트 ② FX 글로우 ③ 전용 도트는 히어로 한정)이 정확히 이 비용 문제의 해답** (기획서 04 §5.1). 테마·어종 파이프라인의 저비용 양산 구조를 지켜야 10년을 버틴다.
2. **비싼 확정가 + 무료 수급 빈곤 = 최다 불만** — "펫이 미쳤게 비싸다, 쿠키 벌 방법이 없다". → 경제 상수(GUARDRAILS §6) 튜닝 시 "무과금도 주 1마리 체감" 같은 수급 하한선을 명시적으로 잡을 것.
3. **오퍼월 불신** — 미적립 오류가 평판을 갉아먹음. → 오퍼월 금지 유지, SSV 검증(이미 서버 구조 있음)으로 미적립 자체를 구조적으로 방지.
4. **iOS 차별 방치** — 구조적 한계를 커뮤니케이션 없이 방치해 3.6점. → iOS는 기능 격차를 숨기지 말고 "위젯+미러 중심" 정체성을 처음부터 다르게 포지셔닝.
5. **유스 편중 커뮤니티** — 초등생 다수 + 인게임 SNS 유해성. → 우리 소셜은 익명 토큰+하트(텍스트 없음)로 저위험 유지. 자유 텍스트 소셜 도입은 신중히.
6. **AI 챗봇 과금 전가 반발**(2023, 대화에 쿠키 소모 → 반발 → 철회) — 운영비를 사용자 과금으로 직결하는 설계 금지.
7. **헬로펫 하우스의 교훈: "상주"를 빼면 그냥 흔한 게임** — IP만 가져가고 오버레이 상주를 뺀 스핀오프는 1년 만에 종료. **우리 정체성 = 라이브 배경 상주. 이걸 희석하는 방향(일반 앱 게임화)은 자충수.**

## 5. 시장 시사점

- 니즈 실증: 홈 화면 상주 생명체는 한국발로 글로벌 900만이 받아준 검증된 감성 카테고리. 2026년 현재도 틱톡에 노스탤지어 수요.
- 공백: 원작은 8년째 신규 콘텐츠 없이 유지보수 모드, 스핀오프는 사망, 대체재 부재 → **"차세대 홈 화면 생명체" 자리가 비어 있음.**
- 차별화 각: 헬로펫 = 유스·캐릭터 개그 톤 / Aqua Desk = **성인 Cozy/Zen·관조 톤 + 죽음 없음 + 저권한 라이브 배경**. 직접 경쟁이 아니라 세대·톤 갈아타기.
