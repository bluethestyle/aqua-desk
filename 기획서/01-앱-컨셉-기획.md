# 01. 앱 컨셉 기획

## 1. 프로젝트 개요

### 1.1 서비스명(가칭)

**「Aqua Desk」** (수족관 데스크) — 명칭은 추후 확정

### 1.2 한 줄 정의

사용자의 **스마트폰 배경(및 홈 화면 위젯 영역)** 에 **도트 스타일 수족관**이 상시 표시되고, **하이브리드 앱**을 통해 수족관을 꾸미고 물고기를 키우며 낚시·상점으로 성장시키는 **라이트 라이프·캐주얼 게임**.

### 1.3 핵심 가치

| 가치 | 설명 |
|------|------|
| **항상 보이는 애완** | 앱을 열지 않아도 홈/잠금에서 물고기가 살아 있음 |
| **가벼운 재미** | 터치 한 번에 물결·도망·호기심 반응 |
| **짧은 세션** | 꾸미기·낚시·상점은 1~3분 단위 |
| **저전력·저용량** | 데이브 더 다이버식 픽셀, 제한된 스프라이트·프레임 |

### 1.4 레퍼런스

- **비주얼**: 《Dave the Diver》 — 굵은 픽셀, 제한 팔레트, 짧은 애니 루프, 작은 스프라이트 시트
- **UX 참고**: 라이브 배경화면 게임, 홈 위젯 수족관, 방치형 키우기(피드·성장만 경량화)

## 2. 사용자 관점 경험(UX)

### 2.1 일상 루프(배경 레이어)

```
[기기 켜기/홈 복귀]
    → 배경 수족관 자동 렌더
    → 물고기 패트롤·식빵/기포 등 앰비언트 모션
    → (선택) 배경/위젯 터치 → 물결 + 물고기 반응
    → (선택) 앱 아이콘 근처 터치(Android 위젯) → 국소 반응
```

### 2.2 앱 루프(하이브리드 레이어)

```
[앱 아이콘 탭]
    → 로비: 내 수족관 미리보기 + 상태(배고픔, 레벨)
    → 꾸미기: 바닥·식물·장식·조명 배치
    → 낚시: 미니게임으로 새 종·재료 획득
    → 상점: 코인/재화로 용품·물고기·먹이 구매
    → 저장 → 네이티브 배경 엔진에 상태 동기화
```

### 2.3 화면 구성(앱 내, 초안)

| 화면 | 역할 |
|------|------|
| **로비** | 수족관 썸네일, 재화, 퀵 액션(먹이, 청소) |
| **꾸미기** | 그리드/슬롯 배치, 인벤토리에서 드래그 |
| **낚시** | 타이밍·당기기 등 1스테이지 미니게임 |
| **상점** | 일일 로테이션, 패키지, 프리미엄(후순위) |
| **도감** | 획득 물고기·희귀도 |
| **설정** | 배경 품질(절전/표준), 알림, 계정 |

### 2.4 터치 반응(재미 요소) — 컨셉

| 트리거 | 반응(예시) |
|--------|------------|
| 배경 탭 | Ripples 0.5~1s, 물고기 scatter → 2s 후 복귀 |
| 같은 영역 연타 | 작은 기포 연출, 희귀 fish peek |
| 위젯 영역 탭(Android) | 위젯 내부만 국소 파문, 아이콘 가리지 않음 |
| 장시간 미접촉 | 느린 drift, 가끔 yawning fish |

**주의**: iOS는 “전체 홈 화면 라이브 배경 + 임의 터치”가 제한적입니다. 상세는 `03-플랫폼-제약-및-대안.md`.

## 3. 게임 디자인

### 3.1 성장·경제(라이트)

| 요소 | 설계 방향 |
|------|-----------|
| **재화** | 코인(일반), 진주(희귀, 낚시/도전) |
| **물고기** | 종별 성장 단계 3~4, 먹이·시간 기반(오프라인 캡) |
| **수족관** | 슬롯 수 제한 → 확장은 레벨/상점 |
| **낚시** | 스태미나 일일 N회, 실패해도 재료 소량 |
| **상점** | 일일 6슬롯 로테이션, 꾸미기 파츠 위주 |

### 3.2 콘텐츠 파이프라인(초기)

1. **MVP 물고기** 5종 + 1종 희귀  
2. **장식** 10종(바닥 3, 식물 4, 오브젝트 3)  
3. **낚시 맵** 1곳  
4. **이벤트** 후속: 계절 스킨, 한정 fish  

### 3.3 그래픽 스펙(데이브 더 다이버 스타일, 저부하)

| 항목 | 가이드 |
|------|--------|
| **해상도** | 물고기 스프라이트 32×32 ~ 48×48, 장식 타일 16×16 |
| **팔레트** | 배경+UI 합산 64색 이내 권장 |
| **애니** | fish swim 4~6프레임, 반응 2~3프레임 |
| **배경** | 패럴랙스 2~3레이어, 정적+저주기 스크롤 |
| **에셋** | 스프라이트 시트 + JSON 메타, WebP/PNG8 |
| **목표** | 배경 RAM < 30MB, CPU 피크 배경화면에서 5% 미만(Android 중급기 기준) |

### 3.4 사운드(후순위)

- 배경: 무음 또는 초저음량 앰비언트(기본 OFF)  
- 앱 내: 짧은 SFX만(먹이, 낚시 성공)

## 4. 시스템 구성(논리)

```
┌─────────────────────────────────────────────────────────┐
│  사용자 기기                                             │
│  ┌──────────────────┐    ┌──────────────────────────┐  │
│  │ Native Shell     │    │ Web App (Vercel)         │  │
│  │ · Wallpaper      │◄──►│ · Lobby / Shop / Fish    │  │
│  │ · Widget (AOS)   │    │ · Decorate / Fishing UI  │  │
│  │ · Bridge / Push  │    └───────────┬──────────────┘  │
│  └────────┬─────────┘                │                 │
│           │         Supabase API      │                 │
│           └────────────┬──────────────┘                 │
└────────────────────────┼────────────────────────────────┘
                         ▼
              ┌──────────────────────┐
              │ Supabase             │
              │ Auth · DB · Storage  │
              │ Edge Fn (선택)       │
              └──────────────────────┘
```

### 4.1 데이터 동기화 원칙

- **진실의 원천(Source of Truth)**: Supabase `aquarium_state`  
- **로컬 캐시**: 네이티브 배경용 경량 JSON + 스프라이트 번들  
- **동기화 시점**: 앱 포그라운드, 백그라운드 주기(15~30분, OS 정책 내), 수동 새로고침

## 5. 타깃·플랫폼

| 플랫폼 | 1차 목표 | 비고 |
|--------|----------|------|
| **Android** | 라이브 배경 + 홈 위젯 + 터치 반응 | 핵심 차별화 |
| **iOS** | 위젯 + (제한적) 잠금/배경 연동 | 라이브 터치 배경은 대안 설계 필수 |

**최소 OS**: Android 10+, iOS 16+ (WidgetKit 기준)

## 6. MVP 범위(프로토타입)

### 포함

- [ ] 게스트/이메일 로그인(Supabase Auth)  
- [ ] 기본 수족관 1종, 물고기 3종  
- [ ] Android 라이브 배경 + 단순 터치 파문  
- [ ] 웹: 로비, 상점(더미 3품목), 꾸미기(슬롯 5개)  
- [ ] 상태 저장·배경 반영 1회 동기화  

### 제외(후속)

- iOS 라이브 배경 수준 동등화  
- PvP, 길드, IAP, 푸시 이벤트  
- 복잡 낚시·스토리
