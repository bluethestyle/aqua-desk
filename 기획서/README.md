## 한 줄 요약

**홈·잠금 화면에서 도트 수족관이 살아 움직이고**, 터치 시 물결·물고기가 반응하며, **전용 앱(웹 UI + 네이티브 셸)** 으로 꾸미기·낚시·상점을 즐기는 **저부하 픽셀 아쿠아리움 게임**.
