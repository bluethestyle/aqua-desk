# 02. UI · UX 디자인 시스템

> 대상: 인터랙티브 UI는 전부 **Next.js 웹앱(WebView)** ([GUARDRAILS §2](../GUARDRAILS.md)). 본 문서는 그 위에 얹는 **픽셀 코지 디자인 시스템**.
> 컬러·타이포 토큰은 [01](./01-아트-디렉션-및-비주얼-아이덴티티.md)의 마스터 램프에서 파생. 화면 목록은 [기획서 01 §2.3](../기획서/01-앱-컨셉-기획.md).

---

## 1. 레이아웃 기초

- **타깃**: 모바일 세로 우선, 디자인 폭 **360–430px**(기준 390). 1컬럼. 세이프에어리어(노치·제스처바) 패딩 반영.
- **그리드 / 간격**: **4px 베이스**, 주 스텝 8. 토큰: `space-1=4 / 2=8 / 3=12 / 4=16 / 6=24 / 8=32`. 픽셀 정합을 위해 4의 배수 고정.
- **모서리**: 안티에일리어싱 둥근 모서리 대신 **2px 계단형(stepped) 픽셀 코너** 또는 직각. 토큰 `radius-pixel = 0`(직각) / `radius-step`(2px 2단).
- **보더**: 1~2px 하드 라인(`ink-600`). 그라데이션·드롭섀도 대신 **1px 픽셀 섀도**(아래 2px 오프셋 `ink-900`)로 깊이.
- **엘리베이션**: 블러 그림자 금지(픽셀 톤 위반). 표면 명도 단계(`ink-800`→`700`)와 1px 외곽선으로 레이어 표현.
- **네비게이션**: 하단 고정 **탭 바 5개** — 로비 · 꾸미기 · 낚시 · 상점 · 도감. 설정은 로비 우상단 진입.

```
┌───────────────────────────┐  ← 세이프에어리어 상단
│  [재화 HUD]          [⚙]  │
│                           │
│      (화면 콘텐츠)         │
│                           │
├───────────────────────────┤
│ 🏠로비 🎨꾸미기 🎣낚시 🛒상점 📖도감 │  ← 하단 탭바(픽셀 아이콘 24px)
└───────────────────────────┘  ← 세이프에어리어 하단
```

## 2. 타이포그래피

> **Readable Retro** 기둥([README](./README.md)): 픽셀은 액센트, 본문은 가독 산세리프. 한글·영문·숫자 모두 또렷해야 함(낚시 1.0s 타이밍·중장년 배려 — [기획서 04 §6.1](../기획서/04-서비스-고도화-및-리스크-대응.md)).

| 역할 | 폰트 | 비고 |
|------|------|------|
| 디스플레이/헤딩/수치/라벨 | **갈무리(Galmuri11, 작은 곳 Galmuri9)** | 한글+라틴 픽셀 폰트, 레트로 액센트. 정수 픽셀 배수(11/22/33px)에서만 렌더 |
| 본문/설명/튜토리얼/긴 글 | **Pretendard**(또는 시스템 한글 산세) | 가독성·중장년 배려. 안티에일리어싱 허용 |
| 숫자 강조(재화 카운트) | 갈무리 + `tabular-nums` | 자릿수 흔들림 방지 |

- **타입 스케일**: `display 22 / h1 18 / h2 16 / body 14 / caption 12 / micro 11`(px). 픽셀 폰트는 11의 정수배 우선.
- **행간**: 본문 1.5, 픽셀 헤딩 1.2. **자간 0**(픽셀 폰트 자간 조정 금지 — 깨짐).
- **라이선스**: 갈무리 웹폰트 **서브셋 임베딩**(사용 글리프만) 확정 필요([README 다이얼](./README.md)).

## 3. 컴포넌트 라이브러리

### 3.1 버튼 (픽셀 베벨)

```
 ┌──────────────┐   기본: 2px 외곽선(ink-900) + 면(brand/coral)
 │  먹이 주기 🐟 │   상단 1px 하이라이트, 하단 2px 픽셀 섀도
 └──────────────┘
 press → 섀도 제거 + 1px 아래로(눌림감), 80ms
```

| 변형 | 면 | 용도 |
|------|----|------|
| Primary | `glow-cyan` 면 + `ink-900` 글자 | 주요 확정(저장·구매) |
| Warm | `coral-warm` | 케어(먹이·청소) |
| Ghost | 투명 + 1px 보더 | 보조·취소 |
| Premium | `glow-gold` 면 + 시머 | 진주/패스 결제 |
| Disabled | `ink-600` 무광 | 토큰 없음·조건 미달(아래 §7 위젯 참조) |

- 탭 타깃 **최소 44×44px**(접근성). 라벨은 아이콘+텍스트 병기.

### 3.2 재화 HUD (상단 상시)

좌상단 칩 묶음. 색 + **아이콘 형태**로 구분(색맹 대응 — [01 §2.3](./01-아트-디렉션-및-비주얼-아이덴티티.md)).

```
( 🪙 1,240 )( 🦪 12 )( ❤ 8 )( ⚡ 4/5 )
  코인        진주     하트    스태미나
```

- 값은 **낙관적 UI 표시용**, 권위는 서버 RPC 결과([GUARDRAILS §9](../GUARDRAILS.md)). `conflict` 시 칩 값 리프레시.
- 증감 시 칩이 짧게 펄스(+숫자 플로트 업), 코지 톤(번쩍임 금지).

### 3.3 카드

| 카드 | 구성 |
|------|------|
| **어항 썸네일**(로비) | 라이브 미니 프리뷰 또는 webp 스냅샷 + 상태배지(만족/불만족) + 평점 별 |
| **도감 카드** | 어종 도트 + 이름 + 희귀도 프레임([§6](#6-희귀도-상태-표기)) + 미획득은 실루엣 |
| **상점 슬롯** | 아이템 도트 + 가격칩(코인/진주) + 남은시간(일일 6슬롯) |

### 3.4 바텀시트 · 모달

- 액션은 **바텀시트**(엄지 도달). 상단 16px 핸들바, `ink-800` 면 + 상단 1px `ink-600`.
- 파괴적/결제 확인만 중앙 모달 + 딤(`ink-900` 60%).

### 3.5 토스트 · 피드백

- 화면 하단 위(탭바 위) 떠오르는 픽셀 토스트, 2.5s 자동 소멸. 색은 시맨틱(성공 `kelp`, 안내 `glow-aqua`).
- **불만족/실패는 부드러운 앰버**, 빨강·해골·진동 경고 금지([01 §2.3](./01-아트-디렉션-및-비주얼-아이덴티티.md), [기획서 04 §1.2](../기획서/04-서비스-고도화-및-리스크-대응.md)).

### 3.6 아이코노그래피

- **16px / 24px 픽셀 아이콘**, 1px(=화면 2px) 스트로크 굵기 통일, 마스터 팔레트 색만. 탭바 24px, 인라인 16px.
- 라인+솔리드 혼용 금지(한 가지 굵기·스타일). 자세한 에셋 규격은 [03 §7](./03-픽셀-아트-에셋-가이드.md).

## 4. 모션 토큰

> **Cozy First** — 부드러운 이징, 급정거 금지. 저모션/저전력은 *디자인 상태*([01 §3](./01-아트-디렉션-및-비주얼-아이덴티티.md)).

| 토큰 | 값 | 용도 |
|------|----|------|
| `dur-instant` | 80ms | 버튼 눌림 |
| `dur-quick` | 160ms | 칩 펄스, 토글 |
| `dur-base` | 240ms | 시트/페이지 전환 |
| `dur-slow` | 400ms | 모달, 강조 등장 |
| `dur-ambient` | 3–8s 루프 | 배경 호흡·God Rays(네이티브) |
| `ease-cozy` | cubic-bezier(0.22,0.61,0.36,1) | UI 기본(부드러운 ease-out) |
| `ease-drift` | linear | 앰비언트 드리프트 |

- **`prefers-reduced-motion` 존중**: 패럴랙스·플로트·시머 OFF, 페이드만. 이는 네이티브 절전 게이팅과 톤을 맞춘다([설계서 03 §2.4](../설계서/03-네이티브-안드로이드-설계.md)).

```
( 재화 HUD )                         (⚙ 설정)
┌─────────────────────────────────┐
│   [ 내 어항 라이브/스냅샷 프리뷰 ]   │

├─────────────────────────────────┤

- 진입 즉시 "살아있음"을 보여줌(라이브/스냅샷). 퀵 액션은 손가락 아래.
- 오프라인 코인 수령은 +숫자 플로트 연출, 광고 2배 옵션 칩([기획서 04 §3.5](../기획서/04-서비스-고도화-및-리스크-대응.md)).

### 5.2 꾸미기 (Decorate)

```
┌─────────────────────────────────┐
│   [ 어항 편집 캔버스(그리드 16px) ] │ ← 드래그 배치, slots만 클라 쓰기
│                                  │
├─────────────────────────────────┤
│  탭: 바닥 | 식물 | 오브젝트 | 조명 | 테마 │
│  [인벤토리 썸네일 가로 스크롤 …]    │
│  평점 미리보기:  ⭐⭐⭐⭐☆ (+풍수)   │ ← 미학→진행 (기획서 04 §4.2)
└─────────────────────────────────┘
 [ 저장 ]  → 네이티브 sync + webp 스냅샷 생성
```

- 배치 슬롯 = 16px 그리드 스냅. **테마 탭**에서 프리미엄 테마 미리보기(셰이더 무드 동시 전환 — [01 §5](./01-아트-디렉션-및-비주얼-아이덴티티.md)).
- 저장 시 위젯용 webp를 **웹앱이 Canvas로 생성**해 업로드([GUARDRAILS §9](../GUARDRAILS.md)).

### 5.3 낚시 (Fishing) — 4단계 미니게임

> 플로우·스킬 매핑 [기획서 04 §6](../기획서/04-서비스-고도화-및-리스크-대응.md). 보상은 전부 서버(`fishing-resolve`), Optimistic UI.

| 단계 | UI |
|------|----|
| 캐스팅 | 가로 **힘 게이지** + Perfect 존(녹색 띠). 적중 시 희귀확률 +10%p |
| 입질 | 찌 가라앉음 + "!" 팝 → **1.0초** 탭 윈도우(완화) |
| 릴링 | 세로 트랙 + 이동 **그린존**, 찌를 3초 유지(탭/홀드↑·떼면↓), 상·하단 끝=실패 |
| 결과 | **선제 성공 연출**(들어올리기 1.5~2s) 후 서버 응답. 응답 지연 시 스피너→타임아웃 재동기화 |

- **불변 규칙 시각화**: 성공 연출 후 "사실 실패" 금지([기획서 04 §6.3](../기획서/04-서비스-고도화-및-리스크-대응.md)). 통신 실패 시 "동기화 중" 안내(증발 금지).
- 게이지/존은 픽셀 톤 + 큰 타깃. 타이밍 색은 색맹 대응 위해 위치/형태 병행.

### 5.4 상점 (Shop)

```
일일 슬롯 6  ·  남은시간 14:32:10        [🔄 광고 무료 리프레시]
┌────┬────┬────┐
│item│item│item│   가격칩(🪙/🦪) · 보유 표시
├────┼────┼────┤
│item│item│item│
└────┴────┴────┘
[ 진주 팩 ]  [ 스타터팩(첫구매) ]  [ 아쿠아 패스 ]
```

- 일일 6슬롯(`daily-shop-roll`). 진주 팩 사다리·스타터팩·패스 카드([GUARDRAILS §6](../GUARDRAILS.md) 상품/가격 — 디자인은 참조만).
- 결제 버튼 = Premium 변형(시머). 가격은 명확·다크패턴 금지(코지 정합).

### 5.5 도감 (Dex)

```
획득 42 / 120        희귀도 필터: [전체|C|R|★]
┌──┬──┬──┬──┐
│🐟│🐠│▦ │▦ │   미획득=실루엣(▦)
├──┼──┼──┼──┤
│★ │🐡│▦ │🐟│   ★=Cosmic 프레임+시머
└──┴──┴──┴──┘

```

- 카드 탭 → 상세(이름·성격·크기 기록·획득처). 미획득 실루엣은 호기심 자극.
- 세트/마일스톤 버프 진행 표시([기획서 04 §4.1](../기획서/04-서비스-고도화-및-리스크-대응.md)).

### 5.6 설정 (Settings)

- **배경 품질**: 표준 / 절전(셰이더 게이팅 직결 — [01 §3](./01-아트-디렉션-및-비주얼-아이덴티티.md)).

## 6. 희귀도 · 상태 표기

- **희귀도 프레임**(색+형태 동시): Common 무광 사각 / Rare 림글로우 모서리 / Cosmic·Mythic 시머 + 모서리 보석. ([01 §2.4](./01-아트-디렉션-및-비주얼-아이덴티티.md), [03 §6](./03-픽셀-아트-에셋-가이드.md))
- **만족/불만족 배지**: 만족 😊(`kelp`) / 불만족 😴 부드러운 앰버 — *경고 아님*. 1회 케어로 즉시 회복([기획서 04 §1.2](../기획서/04-서비스-고도화-및-리스크-대응.md)).
- **성격(Nature) 텔**: 도감·네임플레이트에 작은 성격 아이콘(겁쟁이/먹보/호기심/외톨이 — [기획서 04 §4.4](../기획서/04-서비스-고도화-및-리스크-대응.md), 비주얼은 [03 §6](./03-픽셀-아트-에셋-가이드.md)).

## 7. 위젯 · 알림 · 공유 카드 (네이티브 표면)

> 배경-앱 브리지는 **위젯 + 알림**으로 확정(오버레이/더블탭 폐기 — [기획서 04 §2.2](../기획서/04-서비스-고도화-및-리스크-대응.md)).

### 7.1 홈 위젯 (RemoteViews, P0)

```
┌──────────────────────────┐
│ [어항 webp 스냅샷]         │ ← 웹앱 Canvas 생성 webp (GUARDRAILS §9)
│  😊 만족 · 🪙 1,240        │
│ [ 먹이 주기 ] [ 청소하기 ] │ ← PendingIntent → feed_fish/clean RPC
└──────────────────────────┘
```

- 크기: 2×2(컴팩트) / 4×2(스냅샷+버튼). RemoteViews 제약상 **픽셀 도트 비트맵 + 시스템 버튼**.
- **토큰 없으면 버튼 비활성 + "앱 열기"**([GUARDRAILS §9](../GUARDRAILS.md)). 비가시 시 연출은 큐잉→홈 복귀 flush(R1 — [설계서 03 §4](../설계서/03-네이티브-안드로이드-설계.md)).

### 7.2 진행형 알림 제어센터 (P1)

- 상단 상주 노티: 어항 상태 한 줄 + `[먹이][청소]` 액션. Android 13+ 런타임 권한.

### 7.3 공유 카드 (소셜·바이럴)

```
