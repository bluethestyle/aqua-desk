## 1. 무드: "노스탤직 레트로 코지-젠"

> 한 문장: **GBA 시절의 손맛 나는 굵은 도트** 위에 **현대적 수중 라이팅(God Rays·굴절·발광)** 을 얹어, 켜 두는 것만으로 마음이 가라앉는 *살아있는 도트 수족관*.

| 축 | 지향 (DO) | 배제 (DON'T) |
|----|-----------|--------------|
| **밀도** | GBA/고사양 아케이드급 디테일, 손으로 찍은 셰이딩·딜리트 | 단색 플랫 + 평면 그라데이션의 얕은 플래시게임 톤 |
| **빛** | 셰이더 기반 God Rays·굴절·발광으로 도트 위에 *깊이* | 도트를 덮어버리는 과한 블룸·렌즈플레어 |
| **온도** | 따뜻한 모래·산호 + 차분한 청록 물. 항상 *포근함* | 차갑고 임상적인 네온 일색(사이버펑크 테마 제외), 빨강 경고색 |
| **무게** | 느린 호흡, 부드러운 이징, 둥근 실루엣 | 급정거·하드컷·번쩍임(코지 위반) |
| **정서** | 안온·소유·자랑(귀여움) | 불안·압박·죄책감([기획서 04 §1.1](../기획서/04-서비스-고도화-및-리스크-대응.md) 죽음 없음) |

### 1.1 두 레이어, 한 정체성

같은 비주얼 언어가 **두 표면**에서 일관돼야 한다.

- **라이브 배경(네이티브, OpenGL ES 2.0)** — 풀스크린 도트 + 셰이더. 게임의 *얼굴*. 항상 보이지만 시선을 빼앗지 않는다.
- **앱 UI(WebView, HTML/CSS)** — 인터랙션 표면. 픽셀 감각의 UI 크롬으로 배경과 한 세계처럼.

두 레이어가 같은 팔레트·같은 광원·같은 모션 곡선을 공유하면 "웹뷰 래퍼"가 아니라 *하나의 게임*으로 읽힌다. (iOS App Store 4.2 대응 정합 — [기획서 04 §2.6](../기획서/04-서비스-고도화-및-리스크-대응.md))

## 2. 컬러 시스템

### 2.1 원칙

- **씬 합산 64색 권장** ([기획서 01 §3.3](../기획서/01-앱-컨셉-기획.md)). 마스터 팔레트는 `.aseprite` 팔레트로 고정하고 모든 에셋이 공유.
- 테마 변주는 **색을 새로 찍지 않고** LUT/색상 시프트 셰이더로 처리(3단 전략 ① — [03 §4](./03-픽셀-아트-에셋-가이드.md)).
- UI 크롬도 같은 램프에서 토큰을 뽑아 *배경과 같은 물에 잠긴* 느낌.

### 2.2 마스터 램프 (기본 테마 = 심해)

> hex는 디자인 토큰 기준값. 픽셀 아트는 이 램프 안에서 셰이딩 단계를 고른다.

**잉크 / 중성 (UI 표면·깊은 그림자)**

| 토큰 | hex | 용도 |
|------|-----|------|
| `ink-900` | `#0B1726` | 최심부, 모달 배경, 비네팅 |
| `ink-800` | `#122334` | 앱 기본 배경(다크) |
| `ink-700` | `#1B3247` | 카드·시트 표면 |
| `ink-600` | `#274A63` | 보더·구분선 |

### 2.3 시맨틱·재화 컬러

재화 4종([기획서 04 §3.1](../기획서/04-서비스-고도화-및-리스크-대응.md))은 **색 + 아이콘 형태**로 동시 구분(색맹 대응).

| 의미 | 토큰/색 | 비고 |
|------|---------|------|
| 코인 | `glow-gold` `#F7D77A` | 동그란 동전 실루엣 |
| 진주 | `#F2DDE8` (이리데센트) + glow | 광택 도는 흰-핑크 |
| 하트 | `coral-pink` `#E8728C` | 소셜 카운터 |
| 스태미나 | `glow-cyan` `#6FE3E0` | 번개/물방울 게이지 |
| 성공·먹이 | `kelp` `#3E8E6E` | 초록 |
| 불만족(경고 아님) | `#E0B86A` 부드러운 앰버 | **빨강 금지** — 죄책감 연출 배제([§1.2](../기획서/04-서비스-고도화-및-리스크-대응.md)) |

### 2.4 희귀도 컬러 (Common → Rare → Cosmic/Mythic)

| 티어 | 컬러 | 처리 |
|------|------|------|
| Common | `text-muted` `#9DB4C4` | 무광, 글로우 없음 |
| Rare | `glow-aqua` `#54C8D8` | 림 글로우(FX 패스 ②) + 1~2 액센트 |
| Cosmic/Mythic | `glow-magenta`→`glow-gold` 그라데이션 | 애니메이션 시머·파티클 + 전용 도트(③) |

> 색만으로 구분하지 않는다. 도감/네임플레이트의 **프레임 형태·아이콘**으로도 티어를 표기([02 §6](./02-UI-UX-디자인-시스템.md), [03 §6](./03-픽셀-아트-에셋-가이드.md)).

## 3. 라이팅 언어 (도트 위의 빛)

> ES 2.0 프래그먼트 셰이더로 구현, **셰이더 게이팅 정책**에 따라 강도가 변한다([설계서 03 §2.4](../설계서/03-네이티브-안드로이드-설계.md) / [기획서 04 §2.4](../기획서/04-서비스-고도화-및-리스크-대응.md)). 디자인은 *게이팅이 꺼져도 그림이 성립*하도록 설계한다(빛은 보너스, 도트가 본체).

| 광원 요소 | 비주얼 의도 | 셰이더 | 게이팅 시 |
|-----------|-------------|--------|-----------|
| **God Rays** | 수면에서 비스듬히 내리는 빛기둥, 느린 흔들림 | 상단 그라데이션 + 노이즈 마스크 | 미터치 시 루프 연장, 절전 시 OFF |
| **굴절(Refraction)** | 물의 일렁임으로 배경 레이어 미세 왜곡 | UV 워블 | 미터치 시 일시정지, 절전 시 OFF |
| **발광(Glow/Bloom)** | 바이오루미네선스 오브젝트·물고기 눈 | Additive 블렌딩 패스 | 절전 시 OFF(순수 도트만) |
| **부유 입자** | 물 속 먼지·기포가 빛에 반짝 | 3프레임 스프라이트 파티클 | 저감 |

- **터치 파문(Ripple)**: `RenderEffect`/AGSL는 최소 SDK(API 29)에서 불가 → **3프레임 스프라이트 파티클**로 구현([기획서 04 §2.4](../기획서/04-서비스-고도화-및-리스크-대응.md)). 디자인은 "셰이더 물결"이 아니라 *도트 파문 스프라이트*로 그린다. (0.5~1s, 물고기 scatter → 2s 복귀 — [기획서 01 §2.4](../기획서/01-앱-컨셉-기획.md))

> **저모션/저전력 = 디자인 상태**, 단순 성능 옵션이 아니다. 절전 모드의 "순수 도트만" 화면도 *그 자체로 아름다운 정물*이 되도록 도트 컴포지션을 1순위로 잡는다.

## 4. 낮/밤 환경 사이클

> 전 테마 코어 시스템 ([기획서 04 §4.5](../기획서/04-서비스-고도화-및-리스크-대응.md)). 기기 로컬 시간 기준.

| 구간 | 시간 | 비주얼 |
|------|------|--------|
| **주간(Day)** | 06:00–18:00 | God Rays 풀, 따뜻한 색온도, 모래·산호 채도 ↑ |
| **황혼/여명(Dusk/Dawn)** | 경계 전후 **30~60분 보간** | 색온도·오버레이 알파를 lerp. *하드컷 금지* |
| **야간(Night)** | 18:00–06:00 | 다크 인디고 멀티플라이 오버레이, **물고기 눈·야광 오브젝트만 Additive 점등** |

- 야간 점등 컬러: `glow-cyan`/`glow-magenta`/`glow-gold` — 종·테마별 시그니처.
- 설정에서 **고정 오버라이드**(항상 주간 / 항상 야간) 제공([기획서 04 §4.5](../기획서/04-서비스-고도화-및-리스크-대응.md)).
- 디자인 산출물: 각 테마는 **주간 LUT / 야간 LUT** 2벌 + Additive 점등 마스크 1벌을 납품(전용 도트 추가 없음 — 3단 전략 ①②로 해결).

## 5. 테마 무드보드

> 테마 = 코어 BM([기획서 04 §3.2](../기획서/04-서비스-고도화-및-리스크-대응.md)). 변경 시 그래픽 + 네이티브 셰이더 무드가 함께 전환.
> **형태가 아니라 빛과 색이 바뀐다** — 같은 어종 스프라이트에 테마별 LUT(①) + FX 패스(②)를 적용. 전용 도트(③)는 테마 *히어로 어종 1~2종*만.

### 5.1 심해 (Deep Sea) — 기본

- **무드**: 고요·신비·포근. 게임의 기본값이자 톤의 기준.
- **팔레트**: `water-*` 청록 그라데이션 + 따뜻한 `sand-*` 바닥 + `glow-cyan`/`glow-gold` 점등.
- **라이팅**: 수면 God Rays 강, 부드러운 굴절, 심해 비네팅.
- **시그니처**: 해파리/아귀류의 청록 바이오루미네선스. 차분한 호흡.

### 5.2 사이버펑크 네온 (Cyberpunk Neon)

- **무드**: 도시 야경 어항. 코지 톤은 유지하되 *생기 있는 네온*.
- **팔레트**: 보라-블랙 물 + `glow-magenta`/`glow-cyan` 네온, 홀로그램 산호.
- **라이팅**: FX 패스 ② 적극 — Additive 글로우·홀로그램·미세 스캔라인. 야간에 절정.
- **주의**: "사이버네틱/홀로그램"은 ①(색)이 아니라 ②(빛)다. 전용 도트(③)로 새지 않도록 FX 패스로 구현([기획서 04 §5.1](../기획서/04-서비스-고도화-및-리스크-대응.md)).

### 5.3 에메랄드 포레스트 (Emerald Forest)

- **무드**: 햇살 드는 민물 숲. 가장 밝고 따뜻, 주간감 강조.
- **팔레트**: 에메랄드-골드 물, 이끼 낀 돌, 수련잎, `glow-gold` 반점광.
- **라이팅**: 나뭇잎 사이 얼룩진 God Rays(dappled), 따뜻한 색온도.

### 5.4 테마 납품 체크리스트 (디자인→아트)

각 신규 테마는 다음만 산출하면 된다(곱셈 폭발 방지):

- [ ] 테마 **LUT 2벌**(주간/야간) — 기존 어종 전체 색 변조(①)
- [ ] 테마 **FX 패스 프로파일**(글로우/블룸/스캔라인 강도 — ②)
- [ ] 배경 패럴랙스 **2~3레이어** 도트(테마 전용)
- [ ] 테마 **히어로 어종 1~2종** 전용 도트(③) — 최고 희귀도
- [ ] God Rays/굴절 **셰이더 파라미터 프리셋**(색온도·강도)

## 6. 앱 아이콘 · 브랜드 (방향만 — 별도 워크)

- 아이콘: 어두운 청록 원형 배경 + 중앙 `glow-cyan` 발광 물고기 1마리(시그니처). 작은 사이즈에서도 읽히는 굵은 도트 실루엣.
- 워드마크: 갈무리 계열 픽셀 + 물방울 도트. 라이트/다크 2벌.
- 스토어 키 비주얼: "홈 화면에 살아있는 수족관" 한 컷(실기기 목업) + 테마 3종 비교.

> 로고/아이콘 확정 픽셀 시트는 출시 전 별도 디자인 워크로 분리([README 다이얼](./README.md)).
