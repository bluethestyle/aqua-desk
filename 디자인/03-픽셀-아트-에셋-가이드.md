# 03. 픽셀 아트 에셋 가이드

> 도트 에셋의 **규격·프레임 예산·변주·명명·익스포트**를 못 박는 문서. 아티스트 납품 기준.
> 기술 한계: [기획서 01 §3.3](../기획서/01-앱-컨셉-기획.md)(그래픽 스펙)·[기획서 04 §5](../기획서/04-서비스-고도화-및-리스크-대응.md)(아트 방폭)·[설계서 README](../설계서/README.md)(Aseprite→TexturePacker).
> 런타임 계약: 스프라이트 state enum·`FishSnapshot.x/y`는 [GUARDRAILS §5](../GUARDRAILS.md). 위치 권위는 네이티브 FSM, 아트는 *프레임만* 제공.

---

## 1. 캔버스 규격

| 에셋 | 캔버스(px) | 비고 |
|------|-----------|------|
| 어종 스프라이트(일반) | **32×32 ~ 48×48** | 3형 실루엣([§3](#3-3형-스켈레톤-템플릿)) |
| 히어로 어종(시그니처) | 최대 **64×48** | 테마당 1~2종, 전용 도트(③) |
| 장식 타일 | **16×16** 그리드 | 배수로 큰 오브젝트 구성(32×16 등) |
| UI 아이콘 | **16×16 / 24×24** | 1px 스트로크 통일([02 §3.6](./02-UI-UX-디자인-시스템.md)) |
| 터치 파문 파티클 | 16×16, **3프레임** | AGSL 회피, 스프라이트 파티클([01 §3](./01-아트-디렉션-및-비주얼-아이덴티티.md)) |
| 배경 패럴랙스 | 풀스크린 타일/스트립 | 2~3레이어, 정적+저주기 스크롤 |

- **팔레트**: 씬 합산 64색 마스터 팔레트 공유([01 §2](./01-아트-디렉션-및-비주얼-아이덴티티.md)). 어종별 임의 색 추가 금지.
- 정수 픽셀 그리드 고정, 안티에일리어싱·서브픽셀 금지. 외곽선은 셀렉티브(전부 두르지 않음, 데이브 더 다이버식).
- 셰이딩 단계는 색당 2~3단계로 절제(밀도는 형태·딜리트로, 색 남발 금지).

## 2. FSM 상태별 프레임 예산

> state enum 고정: `idle | swim | scatter | peek | yawn | sulk`([GUARDRAILS §5](../GUARDRAILS.md)). "불만족"은 `satisfied=false` 파생 → `sulk` 톤.
> 프레임 가이드: swim 4~6, 반응 2~3([기획서 01 §3.3](../기획서/01-앱-컨셉-기획.md)). **보간 없음 = 순수 프레임**(메시 디폼 금지 — [기획서 04 §5.2](../기획서/04-서비스-고도화-및-리스크-대응.md)).

| state | 프레임 | 루프 | 의도 |
|-------|:-----:|------|------|
| `idle` | 2–3 | loop | 제자리 호흡, 지느러미 미동 |
| `swim` | 4–6 | loop | 기본 패트롤 |
| `scatter` | 3–4 | once→swim | 터치/위협에 도주(겁쟁이=범위 2배) |
| `peek` | 2–3 | once | 호기심 들여다보기(호기심=확률+30%) |
| `yawn` | 3 | once | 장시간 미접촉 시 하품(앰비언트 생명감) |
| `sulk` | 2 | slow loop | 불만족: 느린 미동 + 숨음 |

- **어종 1종 총 프레임 ≈ 17~23**. 아틀라스/메모리 예산(RAM < 30MB)의 근거.
- 방향: 좌향 1벌 제작 → 우향은 **수평 플립**(별도 드로잉 금지).

## 3. 3형 스켈레톤 템플릿

> 줄여주는 것은 **로직(프레임 진행·트랜스폼)**, 드로잉 공수는 거의 안 줆 — 아티스트 캐파 산정에 반영([기획서 04 §5.2](../기획서/04-서비스-고도화-및-리스크-대응.md)).

| 형 | 실루엣 | 예시 | 공유 |
|----|--------|------|------|
| **방추형(Fusiform)** | 유선형, 좌우로 긴 | 참치·고등어류 | idle/swim/scatter 프레임 진행·꼬리 위상 동일 |
| **원반형(Discoid)** | 납작 둥근, 세로로 넓은 | 엔젤·탱류 | peek 시 정면 틸트 공유 |
| **장형(Elongate)** | 길고 구불 | 장어·실고기류 | swim 사인파 위상 공유 |

- 같은 형은 **상태별 프레임 타이밍·앵커·히트박스 100% 공유**. 아티스트는 실루엣 안에서 색·무늬·디테일만 채운다.
- 앵커: 입 끝(먹이 추적), 무게중심(FSM 이동), 눈(야간 점등 포인트)을 형별로 표준 좌표 고정.

## 4. 3단 테마 변주 파이프라인

> 테마 × 어종 × 모션의 곱셈 폭발 방지([기획서 04 §5.1](../기획서/04-서비스-고도화-및-리스크-대응.md)). 신규 테마가 어종 전체를 새로 그리지 않게 한다.

| 계층 | 기법 | 비용 | 적용 범위 |
|------|------|:----:|-----------|
| ① **컬러 스왑** | LUT / 색상 시프트 셰이더 | ~0 | **모든** 어종·장식의 테마별 색 변조, 낮/밤 LUT |
| ② **테마 FX 패스** | Additive glow·bloom·스캔라인(ES2.0) | 저렴 | *형태가 아닌 빛* — 홀로그램·네온·발광. (사이버펑크의 "사이버네틱"은 여기) |
| ③ **전용 도트** | 신규 스프라이트 | 비쌈 | **히어로 어종 1~2종 한정** |

- 아티스트 납품의 90%는 **베이스 도트 1벌**(중립 팔레트). 테마 색감·발광은 ①②가 런타임 처리.
- "신규 색 효과 요청"이 들어오면 먼저 **②(빛)로 가능한가?**를 판단 → ③(고비용 신규 도트)로 새지 않게 게이트.

## 5. 낮/밤 · 라이팅 납품물

각 어종/장식/배경은 다음을 제공(전용 도트 증가 없이 ①②로 해결 — [01 §4](./01-아트-디렉션-및-비주얼-아이덴티티.md)):

- **베이스 도트**(중립) 1벌
- **야간 Additive 점등 마스크**: 눈·야광 부위만 흰색 마스크(런타임에 `glow-*` 틴트 + Additive)
- (테마별) **LUT 색 변조표** — 아트가 아니라 색 데이터
- 배경: 주간/야간 색온도 프리셋 + God Rays 마스크(노이즈)

## 6. 희귀도 · 성격 · 만족 비주얼 언어

### 6.1 희귀도 (색 + 형태 동시 — 색맹 대응)

| 티어 | 도트 처리 | 도감 프레임 |
|------|-----------|-------------|
| Common | 무광, 글로우 없음 | 단순 사각 보더 |
| Rare | 1~2 액센트 + 림 글로우(FX ②) | 모서리 림 글로우 |
| Cosmic/Mythic | 시머·미세 파티클 + 시그니처 실루엣(③) | 시머 + 모서리 보석 마크 |

### 6.2 성격(Nature Traits) 텔

> FSM 가중치이자 *살짝 보이는* 비주얼 텔. **신규 도트 없이** 행동 + 작은 마커로 표현([기획서 04 §4.4](../기획서/04-서비스-고도화-및-리스크-대응.md)).

| 성격 | 행동 텔 | 마커(도감/네임플레이트) |
|------|---------|--------------------------|
| 겁쟁이 | scatter 범위 2배, 멀리 도주 | 작은 땀방울 아이콘 |
| 먹보 | 먹이 이동속도 1.5배 | 포크 아이콘 |
| 호기심 | peek 확률 +30%, 자주 들여다봄 | 물음표 아이콘 |
| 외톨이 | 군집 이탈, 외곽 단독 패트롤 | 단독 점 아이콘 |

### 6.3 만족 / 불만족(`sulk`) — 코지 규칙

> 죽음·죄책감 금지([기획서 04 §1.2](../기획서/04-서비스-고도화-및-리스크-대응.md)). 불만족은 *부드럽게*, 회복은 1회로 즉시.

| 상태 | 비주얼 처리(전부 ①/알파, 신규 도트 없음) |
|------|------------------------------------------|
| 만족 | 풀컬러, 정상 FSM, 가끔 peek/yawn |
| 불만족(`sulk`) | **알파 ~50% 반투명** + LUT 디새추레이션, 산호/바닥 뒤로 숨음, 느린 `sulk` 루프, Zzz 기포 |
| 회복 | 먹이/청소 1회 → **팝 복귀 + 반짝(스파클)**, 즉시 풀컬러 |

- 금지: 빨강·해골·기울어진 배·하강 화살표 등 *위협/죄책감* 기호([01 §2.3](./01-아트-디렉션-및-비주얼-아이덴티티.md)).

## 7. 장식 · UI 아이콘 규격

- **장식 카테고리**: 바닥(substrate) / 식물(plant) / 오브젝트(object) / 조명(lighting). 16px 그리드 스냅, 평점(풍수) 기여([기획서 04 §4.2](../기획서/04-서비스-고도화-및-리스크-대응.md)).
- 식물·우렁이 등 일부는 idle 미동 2~3프레임. **자동 관리 봇(우렁이)** = 아쿠아 패스 장식([기획서 04 §1.3](../기획서/04-서비스-고도화-및-리스크-대응.md)), 별도 도트 + idle 루프.
- UI 아이콘: 16/24px, 1px 스트로크, 마스터 팔레트, 한 가지 스타일([02 §3.6](./02-UI-UX-디자인-시스템.md)).

## 8. 아틀라스 · 명명 · 익스포트 파이프라인

> 표준 도구: **Aseprite(소스) → TexturePacker(atlas + JSON)**([설계서 README](../설계서/README.md)). 포맷: WebP / PNG8.

### 8.1 소스 / 산출

- 소스: `*.aseprite`(레이어=상태/마스크 분리, 태그=FSM state). 마스터 팔레트 파일 공유.
- 산출: 테마/카테고리별 아틀라스 `.png|.webp` + 메타 `.json`(프레임 rect·앵커·태그).
- 위젯 스냅샷 webp는 **웹앱 Canvas 생성**(아트 아틀라스와 별개 — Edge/native 합성 금지, [GUARDRAILS §9](../GUARDRAILS.md)).

### 8.2 명명 규약 (파일·아틀라스 키)

> 파일/에셋 키 = `kebab-case`([GUARDRAILS §3](../GUARDRAILS.md)). 어종 키는 `fish_species` 카탈로그 id와 1:1 매핑.

```
에셋 키:  fish-clownfish-swim-0
          fish-clownfish-sulk-1
          fish-clownfish-night-mask
          deco-kelp-tall-idle-0
          icon-coin-16
          ripple-particle-0
아틀라스: atlas-fish-base.{webp,json}
          atlas-deco-base.{webp,json}
          atlas-ui-icons.{webp,json}
          atlas-bg-deepsea.{webp,json}
LUT:      lut-theme-cyberpunk-day.png  /  lut-theme-cyberpunk-night.png
```

- 어종 베이스는 **테마 무관 1벌**(`-base`), 테마 색은 LUT로 분리(폴더당 도트 중복 금지 — [GUARDRAILS §10](../GUARDRAILS.md) 중복 정의 금지 정신과 정합).

### 8.3 성능 예산 정합 (왜 이렇게 빡빡한가)

| 목표 | 출처 | 디자인 함의 |
|------|------|-------------|
| 배경 RAM < 30MB | [기획서 01 §3.3](../기획서/01-앱-컨셉-기획.md) | 어종 총 프레임 ≤ ~23, 베이스 1벌 + LUT 변주 |
| CPU 피크 < 5%(중급기) | 〃 | 보간 없는 순수 프레임, 셰이더 게이팅 전제 |
| APK/번들 경량(< 50MB) | [기획서 04 §2.1](../기획서/04-서비스-고도화-및-리스크-대응.md) | WebP/PNG8, 아틀라스 패킹, 전용 도트(③) 최소화 |

## 9. 아티스트 납품 체크리스트 (어종 1종)

- [ ] 3형 중 하나의 실루엣 준수(32~48px, 히어로만 64×48)
- [ ] `idle/swim/scatter/peek/yawn/sulk` 프레임(좌향 1벌, 총 ≤ ~23)
- [ ] 야간 Additive 점등 마스크(눈/야광 부위)
- [ ] 마스터 64색 팔레트만 사용, AA 없음
- [ ] 앵커(입·무게중심·눈) 형 표준 좌표 정합
- [ ] 희귀도 처리(Rare 림글로우는 FX ②로, 신규 색 추가 금지)
- [ ] 성격 마커는 도감용 16px 아이콘 별도(스프라이트 본체 변경 없음)
- [ ] `.aseprite` 소스 + 태그 + kebab-case 키 제출
