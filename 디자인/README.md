## 디자인 5대 기둥 (Design Pillars)

1. **Cozy First, Guilt Never** — 죽음·불안·죄책감 연출 금지. 불만족조차 *부드럽고 회복은 1회*. 빨강 경고/해골 금지, 톤은 항상 따뜻하게. ([기획서 04 §1](../기획서/04-서비스-고도화-및-리스크-대응.md))
2. **Classic Density, Modern Light** — GBA/아케이드급 밀도 높은 클래식 도트 + 현대적 수중 라이팅(God Rays·굴절·발광)의 의도된 충돌. 얕은 플래시게임 톤 배제.
3. **Always-On Calm** — 첫 화면은 라이브 배경. 정적이지만 죽어있지 않은 앰비언트 모션. 시선을 빼앗지 않는 저주기 호흡.
4. **One Identity, Many Moods** — 테마가 바뀌면 *형태가 아니라 빛과 색*이 바뀐다(3단 아트 전략). 어떤 테마든 한 게임으로 보인다.
5. **Readable Retro** — 픽셀은 *맛*, 가독성은 *기능*. 본문·튜토리얼은 또렷한 산세리프(중장년 배려), 픽셀 폰트는 헤딩·수치 등 액센트에 한정.

## 권장 읽기 순서

1. 무드·컬러·라이팅 톤 잡기 → `01`
2. 그 톤으로 화면·컴포넌트 만들기 → `02`
3. 화면에 들어갈 픽셀 에셋 찍기 → `03`

## 미해결 / 디자인 다이얼 (출시 전 확정)

- [ ] 브랜드 로고·앱 아이콘·스토어 키 비주얼 (별도 워크)
- [ ] 64색 마스터 팔레트 최종 확정(`.aseprite` 팔레트 파일로 고정)
- [ ] 갈무리 폰트 라이선스/임베딩 방식(웹폰트 서브셋) 확정
- [ ] 사운드(후순위) — 본 문서 범위 밖, 별도 오디오 가이드 필요 시 분리
